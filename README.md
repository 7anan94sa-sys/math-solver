# حلّال الرياضيات الشامل 🧮
موقع عربي لحل جميع أنواع المعادلات مع شرح الخطوات — يعمل بالكامل داخل المتصفح.

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (بحيث يكون `index.html` في جذر المستودع).
2. من إعدادات المستودع: Settings → Pages → اختر الفرع `main` والمجلد `/ (root)`.
3. سيظهر الرابط خلال دقيقة تقريباً.

## المميزات
- خطية، تربيعية، تكعيبية، درجة 4–6
- قيمة مطلقة، أسية، لوغاريتمية، مثلثية، متباينات
- نظام 2×2 و 3×3، اشتقاق وتكامل، تبسيط وعوامل، OCR من الصور
